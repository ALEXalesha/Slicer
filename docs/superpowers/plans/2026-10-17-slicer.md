# Слайсер для Centauri Carbon - план сборки

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** программа для Windows, которая готовит модель к печати на Elegoo Centauri Carbon в режиме «Новичок» (три выбора) или «Продвинутый» (все настройки), режет её движком ElegooSlicer и надёжно отправляет на принтер с проверкой, что файл дошёл.

**Architecture:** Electron. Главный процесс (Node) держит всё, что трогает диск, движок и сеть: `src/core/*` - чистые модули без Electron, их проверяют `node:test` и fast-check. Окно (`src/renderer/*`) - HTML/CSS/JS с three.js, общается с главным процессом только через `preload.js`. Принтер в тестах - поддельный (`tests/support/fake-printer.js`: HTTP + WebSocket + UDP на 127.0.0.1 с поломками по заказу).

**Tech Stack:** Electron 43, Node 24, `ws` 8, three.js 0.170, fast-check 3, Playwright 1.62 (`_electron`, невидимое окно), electron-builder 26 (NSIS + portable).

**Spec:** `docs/superpowers/specs/2026-10-17-slicer-design.md`

## Что выяснено до плана (замеры 17.10)

- `elegoo-slicer.exe` (ElegooSlicer 1.5.3.5, форк Orca) режет из командной строки: `--datadir <tmp> --slice 0 --load-settings "machine.json;process.json" --load-filaments filament.json --outputdir <dir> [--arrange 1] model.stl ...` -> `<dir>/plate_1.gcode`, куб 20 мм за ~1 с, окон не открывает, в stdout ничего, ошибка = код 127 и строка `Slic3r::CLI::run found error, exit`.
- **Движок сам не разворачивает цепочку `inherits` до конца.** Те же системные пресеты, переданные файлами, дают `filament_density: 0`, ускорение внешней стенки 1000 вместо 5000 и время 18 мин вместо 10; у «Generic PETG @System» стол 45 °C вместо 80. Значит программа сама собирает каждый пресет по цепочке `inherits` (папки `resources/profiles/Elegoo` и `OrcaFilamentLibrary`) и отдаёт движку **полный** JSON без `inherits`. Это и есть «база», и в ней нет недостающих значений.
- Пресет принтера с `"from": "User"` без `inherits` движок отвергает (127) - у принтера оставлять `"from": "system"`. Пресет процесса без `compatible_printers` тоже отвергается - собранный пресет его сохраняет.
- `curr_bed_type` принимается из JSON процесса (`"Textured PEI Plate"` -> в G-code `;curr_bed_type:Textured PEI Plate`).
- В G-code попадает полный путь модели (`EXCLUDE_OBJECT_DEFINE NAME=C_/Users/...`). Модели копировать в папку задания под нейтральными именами.
- Отправка в ElegooSlicer (его журнал `elegoolink.log`): `POST http://<ip>:3030/uploadFile/upload`, куски по 1 048 576 байт, поля `S-File-MD5`, `Check`, `Offset`, `Uuid`, `TotalSize`, `File`. Имена файлов вида `ECC_0.4_旋转花瓶E_Generic PETG _0.2_4h20m.gcode` - с пробелами и иероглифами.
- SDCP (опыт `n8n_pc/scripts/camera_server.py`): WebSocket `ws://<ip>:3030/websocket`, запрос `{Id, Data:{Cmd, Data, RequestID, MainboardID, TimeStamp, From:0}, Topic:"sdcp/request/<MainboardID>"}`; команды 0 статус, 1 атрибуты, 128 старт `{Filename:"/local/<имя>", StartLayer:0}`, 129 пауза, 130 стоп, 131 продолжить, 258 список `{Url:"/local/"}`, 386 камера `{Enable:1}` -> `VideoUrl` (MJPEG). Поиск: UDP `M99999` на порт 3000, ответ с `Data.MainboardIP`. Коды `PrintInfo.Status`: 0 простой, 1 парковка, 5 ставится на паузу, 6 пауза, 7 останавливается, 8 остановлено, 9 завершено, 10 проверка файла, 13 печатает, 16 нагрев, 20 калибровка стола.
- AiForPrinter пишет `%LOCALAPPDATA%\AiForPrinter\state.json` и `alerts\<id>\alert.json` + `frame.jpg`, строки в `alerts\history.jsonl` (`answer: null` - тревога без ответа).

## Global Constraints

- Только Elegoo Centauri Carbon, сопло 0.4, пресеты движка `Elegoo Centauri Carbon 0.4 nozzle` и `0.20mm Standard @Elegoo CC 0.4 nozzle`.
- «Новичок»: на экране ровно три решения - филамент, поправка температуры, поддержки (+ переключатель «Кайма» внутри пункта поддержек). Больше пунктов - провал (анти-цель).
- Поправка температуры: целое число от -15 до +15 °C, шаг 1, подсказка «если слои плохо слипаются - выше, если нитки - ниже».
- Поддержки: «Нет» / «Где нужно» (дерево, только от стола) / «Везде» (дерево, и на модели).
- Филаменты: PLA, PETG, TPU, ABS, ASA. PLA - «Generic PLA @Elegoo Centauri», PETG - «Generic PETG @System» с правками проверенного пресета Алексея, TPU/ABS/ASA - «Elegoo … @ECC».
- Никогда не слать SDCP 386 с `Enable: 0` (ломает камеру всем). Защита в коде формирования запроса, а не в вызывающем.
- Никогда не слать 128 (старт) второй раз за одну отправку, если принтер уже не в простое.
- Тесты не трогают настоящий принтер, камеру, `%APPDATA%\ElegooSlicer`, `%LOCALAPPDATA%\AiForPrinter`: всё через пути из окружения (`SLICER_TEST=1`, `SLICER_AIFP_DIR`, `--user-data-dir`).
- Окна в тестах: `show:false`, `focusable:false`, x=-20000, `requestPointerLock` заглушён, закон «окно невидимо».
- `electron.exe` напрямую не запускать: только Playwright `_electron.launch` с `SLICER_TEST=1`.
- Окно запоминает размер и место (`window-state.js` из Calibrate3dPrinter, байт в байт).
- Темы: пять тем Paint (`themes.css` из Calibrate3dPrinter), языки RU/EN.
- Ничего личного в репозитории: ни путей вида `C:\Users\<имя>`, ни IP принтера, ни MainboardID.
- Выпусков на Gitea не создавать; GitHub - только скриптом публикации.

## Review Focus

1. Модель с кириллицей/пробелами/иероглифами в имени -> на принтере имя только из `[A-Za-z0-9_.-]`, не длиннее 60 символов, и принтер его показывает. Закон в задаче 5.
2. Обрыв связи посреди загрузки большого (30 МБ) файла -> повтор с начала, старт печати только после того, как файл в списке и размер совпал; если принтер уже печатает - не стартовать. Законы в задаче 7.
3. Движок не найден / упал / модель не помещается на стол -> понятное сообщение, а не «ошибка 127». Закон в задаче 4.
4. Две и больше моделей на столе -> одна нарезка с `--arrange 1`, в G-code обе. Закон в задаче 4.
5. Переключение «Новичок» -> «Продвинутый» -> «Новичок» не теряет выбор и не превращает правки «Продвинутого» в тихие отличия «Новичка»: в «Новичке» всегда чистая база + три выбора. Закон в задаче 10.

## Ручная проверка Алексеем (без неё выпуска нет)

1. Нарезать куб 20 мм в Elegoo Slicer (PLA, 0.20 Standard, без поддержек, пластина та же) и в нашей программе; сравнить строки `; key = value` (закон «как ElegooSlicer» на его настоящем G-code).
2. Одна печать «Печать» из нашей программы: файл виден на экране принтера, печать пошла.
3. Какой стороной пластины он печатает (гладкая = High Temp Plate или текстурная = Textured PEI) - от этого стол и `PrintPlatformType`.
