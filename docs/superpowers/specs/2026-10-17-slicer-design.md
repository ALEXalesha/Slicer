# Слайсер для Elegoo Centauri Carbon - описание замысла

Дата: 17.10.2026. Автор описания - Claude по разговору с Алексеем. Статус: ждёт «да» Алексея.

## Зачем
Алексей печатает на Elegoo Centauri Carbon через Elegoo Slicer / OrcaSlicer. Качество печати его устраивает.
Две вещи - нет:
1. **Слишком много настроек**, «глаза разбегаются». Человек, который печатает впервые, не понимает, что трогать.
2. **Отправка файла на принтер ненадёжна**: файл доходит криво или не виден на принтере, приходится отправлять «раз 5».

Свой слайсер выигрывает не качеством нарезки, а **простотой и надёжностью** под один конкретный принтер.

## Цели
- Подготовить модель к печати и напечатать её на Centauri Carbon - быстро и без страха перед настройками.
- **Два режима** (переключатель на виду):
  - **«Новичок»** - базовые настройки подбирает программа. Человек решает только три вещи: **какой филамент**,
    **поправку температуры**, **поддержки**. Каждый пункт объяснён простыми словами.
  - **«Продвинутый»** - все настройки движка (как в Orca), с поиском.
- **Кнопка «Печать»**: отправить файл на принтер по сети и **сразу запустить печать**. Перед запуском убедиться, что файл
  целиком дошёл и принтер его видит; при сбое - повторить автоматически и понятно сказать, в чём дело. Цель: с первого раза.
- **Кнопка «Экспорт на диск»**: сохранить G-code в файл (флешка и т.п.).
- **Панель принтера** - отдельный раздел меню: состояние (печатает/свободен, %, слой, время до конца, температуры сопла и стола),
  видео с камеры, пауза / продолжить / отмена.
- **ИИ-контроль брака** (AiForPrinter) встроен в панель принтера: при браке - заметное предупреждение и предложение паузы.

## Не цели
- Своя нарезка с нуля (геометрия слоёв, периметры, заливка, поддержки) - режет проверенный движок OrcaSlicer/ElegooSlicer.
- Поддержка других принтеров (только Centauri Carbon; архитектура не должна этому мешать, но делать не надо).
- Соревнование с Orca в количестве настроек и тонких функциях.

## Анти-цели (провал, даже если всё работает)
- В режиме «Новичок» снова стена настроек, просто в нашем окне.
- Отправка снова работает «иногда».
- Печать хуже, чем из Elegoo Slicer с теми же настройками.

## Ограничения и то, что уже решено
- Принтер: Elegoo Centauri Carbon в домашней сети. Протокол SDCP (как у Elegoo Slicer), опыт уже есть в n8n_pc (сервер камеры)
  и AiForPrinter: **грабля** - нельзя слать SDCP «выключить поток камеры» (ломает камеру всем, исправлено 09.10).
- Движок нарезки - CLI ElegooSlicer/OrcaSlicer (ElegooSlicer уже установлен у Алексея). Его профиль Centauri Carbon - основа
  «базы» режима «Новичок».
- Калибровки Алексея (Calibrate3dPrinter: 14 профилей, эталон «все работают отлично» для PETG/PLA) - источник базовых
  значений филаментов.
- Платформа - **решение Claude**: программа для Windows на Electron (как Paint, калькуляторы, Хаб), 3D-вид модели - three.js;
  обёртка движка и связь с принтером - Node (без Python, чтобы не тащить .venv; AiForPrinter вызывается как уже работающая
  служба). Установка через InstallAll и release.ps1, выпуск на GitHub ALEXalesha/Slicer (название репо можно сменить).
- Правила проекта Алексея: тесты без видимых окон, законы на каждую найденную ошибку, без личного на GitHub.

## Что остаётся строителю
- Как именно сводить «Новичок» к движку: набор переменных профиля, которые меняются от трёх выборов (филамент, температура,
  поддержки), и всё остальное - фиксированная база.
- Формат обмена с движком (3MF-проект или профили JSON + STL), куда класть временные файлы.
- Проверка «файл дошёл»: сравнение размера/хэша после загрузки по SDCP, повтор, таймауты, понятные сообщения.
- Как показывать камеру (MJPEG принтера или через уже работающий сервер камеры, не мешая ему).
- Набор законов: отправка (подделка принтера в тестах: обрыв, частичная загрузка, файл не появился), нарезка (G-code
  совпадает с нарезкой ElegooSlicer при тех же настройках), режим «Новичок» (на экране не больше N пунктов), панель.
- Название программы.

## Решения Claude (мелкие, можно поправить)
- Модели: открыть STL / 3MF / OBJ кнопкой и перетаскиванием, несколько моделей на столе, автоматическая расстановка.
- Филаменты в «Новичке»: PLA, PETG, TPU, ABS/ASA - значения из калибровок Алексея (Calibrate3dPrinter), где есть.
- Поправка температуры: ползунок ±15 °C от базы филамента, с подсказкой «если слои плохо слипаются - выше, если нитки - ниже».
- Поддержки: «Нет» / «Где нужно» (авто) / «Везде»; там же «Кайма для прилипания» вкл/выкл.
- Качество в «Новичке» одно (стандарт 0.20 мм, профиль Elegoo) - выбор качества только в «Продвинутом».
- Язык интерфейса: русский и английский, темы как в Paint.
- Принтер находится сам в сети (как в Elegoo Slicer), можно ввести адрес вручную; адрес запоминается.
